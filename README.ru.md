# Banana Road Synth

[English](README.md) | **Русский**

Генерация синтетических заплаток на реальных дорожных фотографиях с помощью **Nano Banana Pro**. Сначала модель предлагает бинарную маску, затем рисует изношенные заплатки в указанных местах. Скрипт сохраняет ответ модели, изображение с сохранённым фоном и наложение маски для проверки.

[Статья на Хабре](https://habr.com/ru/articles/993968/) · [Документация Google](https://ai.google.dev/gemini-api/docs/generate-content/image-generation) · [Тарифы API](https://ai.google.dev/gemini-api/docs/pricing)

## Быстрый запуск

Нужны **Python 3.10+** и доступ к Gemini API с генерацией изображений. Запросы платные; локальные тесты API не вызывают.

```bash
git clone https://github.com/HeinrichWirth/banana-road-synth.git
cd banana-road-synth
python -m venv .venv
```

Активация: `source .venv/bin/activate` в macOS/Linux или `.venv\Scripts\Activate.ps1` в Windows PowerShell. Затем:

```bash
python -m pip install -r requirements.txt
```

Задайте переменную окружения `GEMINI_API_KEY`. Для macOS/Linux:

```bash
export GEMINI_API_KEY="your-api-key"
```

Для PowerShell:

```powershell
$env:GEMINI_API_KEY = "your-api-key"
```

Не сохраняйте настоящий ключ в исходниках и коммитах. Файлы `.env` скрипт автоматически не читает.

Сначала проверьте список входов без отправки данных в Google:

```bash
python generate.py --input ./input_images --output ./outputs --limit 1 --dry-run
```

Затем создайте одну пару:

```bash
python generate.py --input ./input_images --output ./outputs --limit 1
```

Без `--limit 1` обрабатывается вся папка с подпапками. Флаги `--evening` и `--semseg` включают дополнительные эксперименты. Каждый добавляет один запрос генерации на новый исходник.

## Что происходит

1. Фотография переводится в RGB с учётом ориентации EXIF.
2. Модель предлагает маску заплаток. Скрипт приводит её к размеру фотографии методом ближайшего соседа и применяет порог **128**, получая значения **0/255**.
3. Фотография и маска передаются модели для генерации заплаток.
4. При необходимости ответ масштабируется до размеров исходника и сохраняется в `generated/` для проверки.
5. В `patches/` сохраняется PNG: внутри маски берутся сгенерированные пиксели, снаружи - исходные.
6. Локально строится красное наложение маски с непрозрачностью **0,35**.
7. По флагам добавляются вечернее освещение и экспериментальная семантическая маска.

Сборка сохраняет декодированные RGB-пиксели вне маски в `patches/` без изменений. Но она не гарантирует, что внутри маски всё нарисовано правильно: перед обучением нужно проверить границы заплаток, геометрию и швы. Вечерний вариант намеренно меняет всё изображение.

Палитра сегментации: чёрный - фон, синий - бордюры, зелёный - дорожная разметка, красный - переходы, белый - знаки. Цвет заменяется ближайшим цветом палитры по расстоянию в RGB. Это унифицирует кодирование, но не исправляет ошибки распознавания.

## Настройки и результаты

Промпты и настройки находятся в [`config.py`](config.py). Переменная `GEMINI_MODEL` переопределяет модель; по умолчанию используется `gemini-3-pro-image`. В эксперименте февраля 2026 года была `gemini-3-pro-image-preview`. Размер генерации явно задан как **1K**, а сохранённые изображения имеют размеры исходника. Масштабирование не восстанавливает отсутствующие детали.

```text
outputs/
├── masks/       # предложенные бинарные маски
├── generated/   # ответ модели в размерах исходника
├── patches/     # сборка с исходным фоном
├── overlay/     # наложение для проверки
├── metadata/    # хеш исходника, модель и промпты
├── evening/     # необязательная смена освещения
└── semseg/      # необязательная сегментация
```

Для `route_a/frame.jpg` сохраняется `route_a/frame.jpg.png`. Так результаты не конфликтуют с `route_b/frame.jpg` и `route_a/frame.png`.

Готовые этапы используются повторно. При изменении исходника, модели или промпта нужна **новая папка результатов**, чтобы не смешивать несовместимые этапы. После ручного редактирования сохранённых результатов тоже используйте новую папку. Не запускайте несколько процессов в одну папку. Ошибка API останавливает обработку; после её устранения можно повторить запуск. Ответ без изображения вызывает понятную ошибку. Пустая маска отклоняется до запроса на генерацию заплаток.

## Стоимость

При стандартном тарифе Pro из статьи один ответ 1K/2K стоит **1120 × $120 / 1 000 000 = $0,1344**. Два основных запроса - **$0,2688 за выходные изображения**, без входов, текстовых/вычислительных токенов и повторных попыток. Оба дополнительных эксперимента увеличивают сумму до **$0,5376** на исходник. Сборка и наложение маски выполняются локально. Перед запуском проверьте [актуальные тарифы](https://ai.google.dev/gemini-api/docs/pricing).

Пробный запуск показывает верхнюю оценку количества генераций, а не точный счёт. В репозитории нет измерения прироста качества детектора; обучение на синтетике следует оценивать на отложенных реальных изображениях.

## Локальная проверка

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют бинаризацию, палитру, сохранение фона, пустые ответы, имена результатов, возобновление этапов и количество необязательных запросов. Используются локальные тестовые данные: без API, списаний и оценки качества генеративной модели.
